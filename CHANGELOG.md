# Changelog

All notable changes to the NotSoDeFi.com Framework.

## [1.0.1] - 2026-08-22

### Changed
- Removed Polkadot (DOT) — its data provider now requires an API key; roster is 8 protocols.
- Framework methodology, criteria, and per-project analyses are now separately licensed (all rights reserved) — see [LICENSE-METHODOLOGY](./LICENSE-METHODOLOGY).
- Homepage now links to sibling projects (NoSinglePoint, SatoshisGrid).

### Fixed
- Metrics API no longer surfaces stale data from previously removed projects.
- Corrected a year typo (2025 → 2026) in several projects' "last updated" dates.

## [1.0.0] - 2026-08-21

Initial release.
